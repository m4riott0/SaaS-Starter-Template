# SaaS Starter Template

A production-oriented starter template for modern SaaS applications, designed to accelerate projects that require a solid authentication flow and payment integration from day one.

Built with a focus on scalability, maintainability, and real-world SaaS foundations, this template provides a practical starting point for products that need secure user access and online billing capabilities.

## Overview

This project serves as a structured example of:

- Authentication with Firebase
- Payment integration with Stripe
- Payment integration with Mercado Pago
- Protected routes using Next.js App Router
- A clean foundation for launching and evolving SaaS products

## Tech Stack

- Next.js 15 with App Router
- Firebase Authentication
- Firestore
- Stripe
- Mercado Pago

## Features

- Secure user authentication flow with Firebase
- Protected application routes
- Stripe integration for online payments
- Mercado Pago integration for local and alternative payment scenarios
- Modular foundation ready for SaaS expansion

## Use Case

This template is intended for developers and teams who want to start a SaaS project with key infrastructure already in place, especially when the application requires:

- User authentication and access control
- Subscription or payment processing
- A modern and scalable Next.js architecture
- Faster setup without compromising code organization
